# anta-agent

> 自带四层记忆的智能体编程框架——用得越多,解释得越少,花得越省,数据不出你的机器。


## 为什么做

团队现有工具的三个问题,anta-agent 逐一回答:

| 痛点 | anta-agent 的回答 | 证据 |
|---|---|---|
| Qoder 慢:5 分钟的活写半小时 | 本地 CLI,微内核 harness,即打即显 | TUI 流式输出,底部统计行实时刷新 |
| 积分贵、不够用 | 记忆注入砍掉重复上下文;稳定记忆块保住 prompt cache | 底部统计行显示缓存命中率与美元成本 |
| Claude Code 安全顾虑 | 数据全本地;向量化可完全关闭;记忆内容按不可信输入净化 | `~/.anta-agent` 全部文件可打开检查 |

## 它是什么

`at` 两个字母启动。anta-agent 是一个完整的智能体编程框架(agent harness),内核只负责会话循环、事件总线与能力注册,其余一切皆插件:

| 能力层 | 内容 |
|---|---|
| 模型适配 | Anthropic、OpenAI、Google、Bedrock 多厂商,内置 llama.cpp 本地模型 |
| 工具链 | 读文件、执行命令、精确编辑、写入、内容检索、目录扫描,全套编程工具 |
| 上下文管理 | 会话树、自动压缩、扩展与技能系统,TUI 与脚本双模式 |
| **记忆引擎(本产品核心差异)** | 四层记忆:自动记录、后台蒸馏、下次会话自动召回注入 |

```
你 ──对话──► L0 全量记录 ──后台蒸馏──► L1 原子记忆 ──周期合并──► L2 场景 ──沉淀──► L3 人格
                                                                                  │
下次提问 ◄── 自动召回注入(关键词+语义混合检索)◄──────────────────────────────────┘
```

## 四层记忆

| 层 | 存什么 | 形态 |
|---|---|---|
| L0 对话 | 每一轮对话全文,一个字不丢 | 按天 JSONL(事实源)+ SQLite 检索投影 |
| L1 原子记忆 | 蒸馏出的偏好、事实、任务、方法、产出 | SQLite 结构化记录,带类型与优先级 |
| L2 场景 | 相关记忆合并成的场景叙述 | `scene_blocks/*.md` |
| L3 人格 | 所有场景沉淀出的长期工作画像 | `persona.md`,固定注入系统提示 |

**捕获全自动。** 对话结束即记录;每 5 轮(冷启动 1→2→4 递增)或空闲 10 分钟后,后台管道蒸馏出 L1 记忆——带大模型去重,每条新记忆只有四种命运:新建、更新、合并、丢弃。管道永不阻塞正在进行的对话。

**召回混合且省缓存。** 每次请求前,SQLite 关键词与向量语义两路检索、倒数排名融合,把最相关的记忆注入消息;persona 等稳定内容追加在系统提示尾部,不随对话变化,模型厂商的 prompt cache 保持有效。中文英文一次检索全覆盖。

**随时可深挖。** agent 有两个内置记忆工具:`memory_search` 查结构化记忆、`conversation_search` 翻原始对话原文;`/remember <文本>` 当场固化一条规矩;`/memory` 一眼看库内状态。

**完全可选。** 一项配置关闭记忆引擎,anta-agent 退化为普通编程助手,数据原样保留在磁盘。

## 省积分的两笔账

1. **不重复解释**:项目背景、团队规范、个人偏好都在记忆里,新会话不用重新粘贴上下文——token 从源头省掉。
2. **缓存不失效**:系统提示里的记忆块设计为跨轮稳定,prompt cache 命中率直接抬升。底部统计行实时显示 `命中 xx%`,每一轮的钱花在哪看得见。

## 数据与安全

- 所有数据在 `~/.anta-agent`:一个 SQLite 库、按天 JSONL、场景块、人格文档、审计日志。无云端账户,无同步。
- 唯一网络流量:你配置的模型厂商(不可避免),以及**可选**的向量化接口。`embedding.provider: "none"` 时零额外外发,语义检索自动降级纯关键词。
- 记忆内容按不可信输入处理:注入标记中和、控制字符剥离、超长截断,防止记忆投毒逃出注入块。
- 每次记忆写入/更新/合并都有追加式审计记录;人格文档改动自动留备份。
- JSONL 日志是事实源,SQLite 只是检索投影——数据库损坏,重启从日志重放重建。

## 快速开始

```bash
npm install -g anta-agent
at        # 首次运行引导配置模型
```

## 命令与工具

| 项 | 类型 | 用途 |
|---|---|---|
| `/remember <文本>` | 命令 | 立刻保存一条长期记忆 |
| `/memory` | 命令 | 记忆库状态(计数、上次蒸馏时间) |
| `memory_search` | 工具 | agent 检索结构化记忆(L1) |
| `conversation_search` | 工具 | agent 检索原始对话(L0) |

## 存储

```
~/.anta-agent/
  memory/
    memory.db          SQLite:对话、记忆、FTS 与向量索引
    conversations/     按天 JSONL(事实源,可重建投影)
    records/           记忆写入/更新/合并审计
    scene_blocks/      L2 场景块 + 索引
    persona.md         L3 人格文档(.backup/ 留存历史版本)
    .metadata/         管道检查点(断点续跑)
```


## 设计来源

harness 分层参考了 DeepSeek Harness 的插件化内核哲学(内核只拥有注册与生命周期,能力沿接缝生长)与 Claude Code 的智能体工具链形态;记忆引擎的分层模型、去重决策、混合召回设计。
