Retrieval & injection

关键词 + 向量融合；动态与稳定上下文分流

第一约束不是“塞更多记忆”，而是保住 provider prompt cache。

个人库万级条目线性扫描仍是毫秒级；不引入原生向量扩展是明确的工程权衡，而非能力缺失。
嵌入默认关闭：provider: "none"。配置 OpenAI 兼容端点后，后台 32/批回填；失败降级关键词。
两股注入，隔离变化频率
动态
<relevant-memories>

稳定
<user-persona>
<scene-navigation>
<memory-tools-guide>
追加到系统提示尾部，跨轮稳定，保住 provider prompt cache。
注入不够时调用 memory_search / conversation_search；工具指南硬限每轮合计 ≤3 次。
recall/recall-context.ts 模型或维度变化时自动清空并重新嵌入
